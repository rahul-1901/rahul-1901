## `> cat principles.md`

| | Principle | In practice |
|---|---|---|
| 🧱 | **Isolate failure** | Services are separate; the gateway never blocks on Redis, so one slow dependency can't take the app down. |
| 📈 | **Measure everything** | Prometheus metrics on the stack, so performance work starts from data. |
| 🔁 | **Make retries safe** | Idempotent writes (client IDs) plus an outbox with backoff, so flaky networks don't lose messages. |
| 🔔 | **Real-time feel** | Web push, streaming (SSE) AI replies and an installable PWA. |
| 🧠 | **Think in algorithms** | Problem solving and DSA in C++, because the right data structure beats more hardware. |
